# TaskMate

TaskMate is a simple offline task-management application built with Expo, React Native, and TypeScript. It helps users organize daily work and monitor their completion progress.

## Features

- Create, edit, complete, and delete tasks
- Set task priorities and due dates
- Filter tasks by status
- View overall completion progress
- Store tasks locally for offline use
- Run on Android and the web

## Run the Project

```bash
npm install
npx expo start
```

## Development Checks

```bash
npm test
npx tsc --noEmit
npx expo lint
```
